# 미리

미래의 큰 지출(생일, 경조사, 여행, 전자제품 교체 등)을 등록하면
**이번 달 확보해야 할 준비금**과 **자유롭게 쓸 수 있는 돈(예상 여유 예산)**을 계산해 주는 개인용 모바일 웹앱입니다.

- 서버·로그인 없음. 데이터는 브라우저 `localStorage`에만 저장 (설정 → JSON 내보내기/불러오기로 백업)
- 빌드 없음. HTML/CSS/ES 모듈 그대로 GitHub Pages에서 동작

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 껍데기, 하단 탭 |
| `styles.css` | 디자인 토큰(`--accent`, `--accent-soft` …)과 스타일 |
| `app.js` | 화면(홈 / 계획 / 추가·수정 / 달력), 상세·설정 시트 |
| `calc.js` | 계산 로직 (DOM 없음) |
| `store.js` | 저장, 백업/복원, 예시 데이터 |
| `icons.js` | 선 아이콘 |
| `manifest.webmanifest`, `sw.js`, `icons/` | 홈 화면에 추가, 오프라인 |

## 계산 규칙

- **한 달** = 월급날 ~ 다음 월급 전날. 급여일이 그 달에 없으면(29~31일) 말일로 보정.
- **준비 횟수** = 이번 달 1회 + 필요한 날짜 *전에* 돌아오는 월급날 수. 필요한 날짜가 이번 달 안이면 1회(남은 금액 전액).
- **준비 가능 금액**: 매달 = 월급 − 고정지출 − 적금 − 생활비. 이번 달(현재 월급 주기) = max(통장 잔고 − 다음 월급 전까지 나갈 돈, 0).
  잔고는 은행 앱을 보고 직접 입력 (확보해 둔 준비금은 뺀 쓰는 통장 잔고). 넣은 적이 없으면 매달 준비 가능 금액으로 대신.
- **준비금 배분** (여유 있는 달에 더): 기한 빠른 계획부터, 기한 전 월급 주기마다 고르게 나눈 몫을 준비 가능 금액 안에서 채움.
  모자란 몫은 다음 달로 넘기고, 기한까지 못 채우면 기한 전 남은 자리를 마저 씀. 그래도 남으면 그 계획은 '부족'.
  이번 달 몫은 그 달 시작 시점 기준이라, 이번 달에 확보액을 기록해도 흔들리지 않음.
- **다음 월급날까지 쓸 수 있는 돈** = 잔고 − 나갈 돈 − 이번 달에 모을 돈 − 다음 월급 전에 필요한데 못 채운 금액.
- **월별 전망** (월별 탭, 홈 '달별 계획'): 달마다 모을 돈과 쓸 수 있는 돈(생활비 포함). 다음 달부터는
  월급 − 고정지출 − 적금 − 그 달에 모을 돈 − 그 달이 기한인데 못 채운 금액. 최소 6개월.
- **월급**: 설정에는 기본 월급(야근·보너스 제외)을 적고, 실제로 받은 금액이 다른 달은 월별 탭 '이 달 금액 고치기'에서 그 달만 고침. 고정지출 항목도 그 달만 고칠 수 있음(보너스 달 십일조 등). 그 달 계산에만 반영.
- **이번 달 큰 지출** (월별 탭 이번 달 카드): 이름 + 금액으로 넣고 빼는 항목. 잔고를 고친 뒤에 넣은 것만 이번 달 쓸 수 있는 돈·준비 가능 금액에서 뺌 (그 전 것은 잔고에 반영된 것으로 봄). 잔고를 넣은 적 없으면 이번 달 것을 모두 뺌. '내년에도'를 누르면 1년 뒤 같은 날짜로 계획 생성.
- **고정지출** = 설정에 적은 항목(넷플릭스, 휴대폰 요금 …)의 합계.
- **이번 달 예상 여유 예산** = 월급 − 고정지출 − 적금 − 생활비 − 이번 달 준비금 합계 (계좌 잔액이 아닌 예상치).
- **지출 완료·취소**한 계획은 계산에서 빠짐 (실제로 쓴 달에 이중 계산하지 않음).
- 오늘 날짜는 기기 시간대와 무관하게 Asia/Seoul 기준.
- 기한까지 못 모으는 계획이 있거나 여유 예산이 마이너스면, '희망' → '조정 가능' 순으로 1~3개월 늦췄을 때 바뀌는 준비금·부족액을 제안 ('필수' 제외, 늦춰도 소용없는 계획은 빼고, 자동 변경 없음).
