# 미리

미래의 큰 지출(생일, 경조사, 여행, 전자제품 교체 등)을 등록하면
**이번 달 확보해야 할 준비금**과 **자유롭게 쓸 수 있는 돈(예상 여유 예산)**을 계산해 주는 개인용 모바일 웹앱입니다.

- 서버·로그인 없음. 데이터는 브라우저 `localStorage`에만 저장 (설정 → JSON 내보내기/불러오기로 백업)
- 빌드 없음. HTML/CSS/ES 모듈 그대로 GitHub Pages에서 동작

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 껍데기, 하단 탭 |
| `styles.css` | 디자인 토큰(`--accent`, `--accent-soft` …)과 스타일 |
| `app.js` | 화면(홈 / 계획 / 추가·수정 / 달력), 상세·설정 시트 |
| `calc.js` | 계산 로직 (DOM 없음) |
| `store.js` | 저장, 백업/복원, 예시 데이터 |
| `icons.js` | 선 아이콘 |
| `manifest.webmanifest`, `sw.js`, `icons/` | 홈 화면에 추가, 오프라인 |

## 계산 규칙 (월급 봉투 방식)

- **한 달** = 월급날 ~ 다음 월급 전날. 급여일이 그 달에 없으면(29~31일) 말일로 보정.
- **월급**: 설정의 기본 월급(야근·보너스 제외). 실제 금액이 다른 달은 월별 탭에서 그 달만 고침. 고정지출 항목도 그 달만 고칠 수 있음.
- **남는 돈(저축할 돈)** = 월급 − 고정지출 − 적금 − 생활비 − 계획에 모을 돈 − 기한인데 못 모은 돈
  이번 달은 여기에 이번 달 지출을 반영:
  - **생활비** 지출: 생활비 예산에서 빠지고, 넘긴 만큼만 남는 돈에서 빠짐
  - **계획** 지출: 그 계획에 모아 둔 돈(확보액)에서 나가고 계획은 '지출 완료'. 더 쓰면 차이만 남는 돈에서 빠지고, 덜 쓰면 남은 돈이 돌아옴
  - **그 외** 지출: 남는 돈에서 바로 빠짐
  - **들어온 돈**: 남는 돈에 더해짐
- **준비 횟수** = 이번 달 1회 + 필요한 날짜 *전에* 돌아오는 월급날 수.
- **준비금 배분** (여유 있는 달에 더): 매달 모을 수 있는 돈 = 월급 − 고정지출 − 적금 − 생활비 (이번 달은 이번 달 지출도 뺌).
  기한 빠른 계획부터 기한 전 달마다 고르게 나눈 몫을 채우고, 모자란 몫은 다음 달로. 기한까지 못 채우면 '부족'.
- 지출 완료·취소한 계획은 배분에서 빠짐. 오늘 날짜는 Asia/Seoul 기준.
- 기한까지 못 모으는 계획이 있거나 남는 돈이 마이너스면 '희망' → '조정 가능' 순으로 날짜 늦추기 제안 ('필수' 제외, 자동 변경 없음).

## 개발

```sh
npm test                 # = node --test (계산 로직 테스트)
python3 -m http.server   # http://localhost:8000 에서 확인 (ES 모듈이라 file://로는 안 열림)
```
